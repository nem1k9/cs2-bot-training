# 📦 Сжатый Workflow - Экономия места на Drive

## 🎯 Зачем это нужно?

**Проблема:** Демки CS2 очень большие (~1GB каждая), 20 демок = ~20GB на Google Drive

**Решение:** Скачиваем с HLTV, сжимаем в ZIP архив → экономия ~30-50% места!

---

## 🚀 Быстрый старт

### 1️⃣ Скачай и сожми демки на своём ПК

```bash
python download_and_compress.py
```

**Что произойдёт:**
- Скачает 20 демок топовых команд с HLTV
- Сожмёт их в `cs2_demos_compressed.zip`
- Размер: ~10-15 GB (вместо 20 GB)

**Время:** ~30-60 минут

---

### 2️⃣ Загрузи архив на Google Drive

1. Открой Google Drive
2. Загрузи файл `cs2_demos_compressed.zip` в корень Drive
3. Или создай папку и укажи путь в ноутбуке

---

### 3️⃣ Запусти обучение в Google Colab

**Прямая ссылка:**
```
https://colab.research.google.com/github/nem1k9/cs2-bot-training/blob/main/CS2_Bot_Training_Compressed.ipynb
```

**Что делать:**
1. Открой ссылку
2. Runtime → Change runtime type → T4 GPU
3. Запусти все ячейки по порядку
4. Ноутбук автоматически:
   - Подключит Drive
   - Распакует архив
   - Распарсит демки
   - Обучит модель
   - Сохранит результаты

**Время обучения:** ~2-4 часа

---

## 📊 Сравнение методов

| Метод | Размер | Скорость загрузки | Блокировки |
|-------|--------|-------------------|------------|
| **FACEIT .zst** | ~17 GB | Средняя | ❌ Блокируется |
| **HLTV .dem** | ~20 GB | Медленная | ✅ Работает |
| **HLTV ZIP** | ~10-15 GB | Быстрая | ✅ Работает |

**Вывод:** ZIP архив - лучший вариант! 🔥

## ⚙️ Настройки

### В `download_and_compress.py`:

```python
N_DEMOS = 20  # Количество демок (рекомендуется 20)
DEMO_DIR = "./demos"  # Временная папка
OUTPUT_ZIP = "cs2_demos_compressed.zip"  # Имя архива
```

### В Colab ноутбуке:

```python
DRIVE_ZIP_PATH = "/content/drive/MyDrive/cs2_demos_compressed.zip"  # Путь к архиву
PLAYER = "donk"  # Имя игрока для фильтрации (или None для всех)
```

---

## 🎮 Фильтрация по игроку (опционально)

Если хочешь обучить модель на конкретном игроке:

1. **В Colab ноутбуке** установи:
   ```python
   PLAYER = "donk"  # или "ZywOo", "s1mple" и т.д.
   ```

2. Парсер будет отслеживать **только его действия**:
   - Движение и позиционирование
   - Прицеливание и стрельба
   - Использование гранат
   - Тактические решения

3. Если `PLAYER = None` → парсятся все игроки

## 💡 Советы

### Экономия места:
- После создания архива можешь удалить папку `./demos/`
- Все демки сохранены в ZIP архиве

### Ускорение загрузки:
- Загружай архив на Drive через браузер (не через приложение)
- Используй стабильное подключение

### Если мало места на Drive:
- Уменьши количество демок: `N_DEMOS = 10`
- Или используй Google Drive платный план (100GB за $1.99/мес)

## 🔧 Устранение проблем

### Ошибка: "Архив не найден"
**Решение:** Проверь путь в ноутбуке:
```python
DRIVE_ZIP_PATH = "/content/drive/MyDrive/cs2_demos_compressed.zip"
```

### Ошибка: "No module named 'beautifulsoup4'"
**Решение:** Установи библиотеку:
```bash
pip install beautifulsoup4
```

### Демки не скачиваются с HLTV
**Решение:** 
1. Проверь интернет-соединение
2. Попробуй через VPN
3. Используй `get_demo_links.py` для прямых ссылок
