# 🔥 Обучение на лучших матчах donk

## 🎯 Что это?

Специальный workflow который:
1. **Находит матчи donk с KD >= 1.30** (только его лучшая игра!)
2. **Скачивает эти демки** с HLTV
3. **Анализирует ТОЛЬКО действия donk** (не других игроков)
4. **Обучает AI** копировать его стиль в пиковой форме

---

## 🚀 Два способа использования:

### Способ 1: Всё в Colab (рекомендуется)

**Открой в Colab:**
```
https://colab.research.google.com/github/nem1k9/cs2-bot-training/blob/main/scripts/CS2_Bot_Training_Donk_Best.ipynb
```

**Что делать:**
1. Runtime → Change runtime type → T4 GPU
2. Запусти все ячейки
3. Жди ~3-5 часов
4. Готово!

---

### Способ 2: На своём ПК

**1️⃣ Установи библиотеки:**
```bash
pip install requests beautifulsoup4 tqdm awpy pandas pyarrow torch
```

**2️⃣ Скачай лучшие матчи donk:**

**Настройки в файле:**

**3️⃣ Парси демки:**
```bash
python parse_demos.py
```

**4️⃣ Обучи модель:**
```bash
python train.py
```

---

## ⚙️ Настройки KD

| MIN_KD | Описание | Количество матчей |
|--------|----------|-------------------|
| **1.50+** | Супер-матчи | Мало (~5-10) |
| **1.30+** | Отличная игра | Средне (~15-25) |
| **1.20+** | Хорошая игра | Много (~30-50) |
| **1.10+** | Нормальная игра | Очень много |

**Рекомендация:** `MIN_KD = 1.30` - оптимальный баланс качества и количества

## 📊 Что анализируется?

### Движение:
- Позиционирование на карте
- Скорость передвижения
- Использование присеста
- Пики углов

### Прицеливание:
- Yaw и pitch (горизонталь/вертикаль)
- Скорость поворота мыши
- Использование скопа
- Точность стрельбы

### Гранаты:
- Флешки (timing и позиции)
- Смоки (линапы)
- HE гранаты
- Молотовы/инсендиари

### Тактика:
- Дистанция до врагов
- Выбор позиций
- Ротации
- Тайминги

## 🔧 Устранение проблем

### Ошибка: "HLTV блокирует запросы"
**Решение:**
1. Используй VPN
2. Увеличь задержки в коде (time.sleep)
3. Или скачай на своём ПК (не в Colab)

### Ошибка: "Не найдено матчей с KD 1.30+"
**Решение:**
1. Уменьши MIN_KD до 1.20
2. Проверь что ID игрока правильный (21421 для donk)
3. Возможно изменилась структура HLTV

### Ошибка: "Демка недоступна"
**Решение:**
- Некоторые старые матчи не имеют демок
- Скрипт автоматически пропустит их
- Увеличь N_DEMOS чтобы компенсировать
